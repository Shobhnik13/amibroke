# amigmi

Track your AI coding tool spend and compete on the global leaderboard.

**For installation and usage instructions, visit [amigmi.xyz](https://amigmi.xyz)**

---

## Quick start

```bash
bunx amigmi init <your-token>
```

Get your token at [amigmi.xyz](https://amigmi.xyz) after signing in with GitHub.

## Commands

```bash
bunx amigmi init <token>   # authenticate this machine
bunx amigmi sync           # push latest usage data
bunx amigmi help           # show help
```

## Supported tools

- Claude Code
- Codex
- OpenCode
- More coming soon

## Uninstall

```bash
rm -rf ~/.config/amigmi
```
